# Wejdan AlHarby — Portfolio

A personal portfolio website built with **React** and **Vite**, developed during my **Software Engineering Internship at Smart Methods (Web Development Track)**.

🔗 **Live site:** [portfoliosm01.netlify.app](https://portfoliosm01.netlify.app/)

## ✨ Features

- **Animated starfield background** — a canvas-based field of soft, twinkling stars with a gentle glow, rendered smoothly across the whole site without affecting performance
- **Typing intro animation** — the name types itself in on load, followed by a slow-typed quote that fades away to reveal the bio
- **Interactive project showcase** — categorized tabs (Web Projects, Game Dev, Robotics & Engineering) with a swipeable/scrollable carousel
- **Live tech stack marquee** — an infinitely scrolling strip of real technology logos
- **"Laser sweep" hover effect** on cards across the site
- **Contact form modal** with subject, message, and phone number fields
- **One-click Resume download** — generates a formatted PDF resume on the fly from the site's own data, so it's always up to date
- **Warm-up robot animation** in the "Let's Build Something Together" section
- Fully responsive across desktop, tablet, and mobile

## 🛠️ Tech Stack

React · Vite · JavaScript (ES6+) · CSS3 · jsPDF · Lottie
